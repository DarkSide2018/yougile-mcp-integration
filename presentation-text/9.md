1. Давайте разберемся с MCP-серверами. MCP расшифровывается как
2. Model Context Protocol. Это протокол, который придумала Anthropic
3. (та самая компания, где работает Дарио Амодей из слайда 3).
4. Суть простая: MCP — это USB-C для AI-агентов.
5. Как через USB-C мы подключаем к ноутбуку монитор, мышку,
6. клавиатуру и всё работает по единому стандарту,
7. так и через MCP агент подключается к внешним инструментам.
8. Раньше для каждого внешнего сервиса нужно было писать свою
9. интеграцию, свой парсер, свою аутентификацию. MCP это унифицирует.
10. Агент просто говорит: «у тебя есть тулза create_yougile_task?»,
11. MCP-сервер отвечает: «да, вот её сигнатура», и агент сам решает,
12. когда и с какими параметрами её вызвать.
