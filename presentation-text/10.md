1. В нашем проекте MCP-сервер выступает прослойкой между
2. AI-агентом и YouGile — системой для управления задачами.
3. Сам сервер написан на Kotlin, внутри у него четыре инструмента:
4. create_yougile_task — создать задачу,
5. list_yougile_boards — показать доски,
6. list_yougile_users — показать пользователей,
7. list_yougile_columns — показать колонки на доске.
8. Агент отправляет JSON-RPC запрос по HTTP,
9. MCP-сервер принимает его, дёргает REST API YouGile
10. и возвращает результат. Агенту не нужно знать,
11. как устроен API YouGile, какой там эндпоинт,
12. какой токен передавать — всю работу делает MCP-сервер.
13. Это и есть главная идея: агент работает с абстракцией,
14. а не с конкретным API.
