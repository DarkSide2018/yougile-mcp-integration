1. сервер написан на Kotlin, внутри у него четыре инструмента:
2. MCP-server можно написать самому - это не так уж и сложно
3. Либо использовать уже готовый
4. create_yougile_task — создать задачу,
5. list_yougile_boards — показать доски,
6. list_yougile_users — показать пользователей,
7. list_yougile_columns — показать колонки на доске.
8. Агент отправляет запрос по HTTP,
9. MCP-сервер принимает его, дёргает REST API таск-трекера
10. и возвращает результат. Агенту не нужно знать,
11. как устроен API таск-трекера, какой там эндпоинт,
12. какой токен передавать — все эти вопросы и нюансы закрывает MCP-сервер.
13. Это и есть главная идея: агент работает с абстракцией,
14. а не с конкретным API.
